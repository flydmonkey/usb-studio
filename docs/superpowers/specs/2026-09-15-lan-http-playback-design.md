# 局域网 HTTP 播放

Approved 2026-09-15.

设置里增加「局域网播放」开关（默认关）。打开后本机起 HTTP 服务，界面显示可复制地址，例如 `http://192.168.1.8:8080/`。同一 Wi-Fi 下用浏览器打开该地址即可。**不插采集卡也能看已录成片**；现场画面要等采集卡连上。Android 先做（红米当服务器）；iPad 这期不做。不设密码、不做外网穿透、不做 HTTPS。

## 使用方式

- 开关在采集设置中，偏好持久化。
- 有 Wi-Fi（或能拿到局域网 IPv4）才显示地址；否则提示先连网。
- 浏览器打开首页：上方现场播放器（HLS，H.264 + AAC，延迟大约几秒）；下方片库列表，点一条即播该 MP4。
- 可与本地分段录像、RTMP 推流同时开。现场编码与 RTMP 共用同一路 H.264/AAC（有推流则 tee 到 HLS，没有则单独为 HLS 编码）。
- 开关开着时用前台通知保活，锁屏后同一局域网仍能打开地址。

## 服务与路径

本机绑定 `0.0.0.0`，优先端口 `8080`，占用则递增并更新界面上的 URL。

| 路径 | 行为 |
| --- | --- |
| `GET /` | 自带播放器的 HTML 页（现场用 hls.js；成片用 `<video>`） |
| `GET /live.m3u8` 与切片 | 现场 HLS。采集卡未打开时返回可读失败（页面显示等待采集卡） |
| `GET /vod/<id>` | 已保存 MP4，支持 HTTP Range，边下边播 |

成片列表与现有片库同源（相册 / 影片 / 下载 / 自定义文件夹）。拔采集卡只停现场，VOD 继续。

## 错误与限制

- 没网：不显示地址，说明先连 Wi-Fi。
- 端口占用：换端口，界面跟新地址。
- 文件不在了：该条 404，不影响其它条目。
- 现场编码进行中：格式 / 画质与推流同样锁定。
- 同一 Wi-Fi 上任何人打开该地址都能看（设置里用一句话说明）。

## 非目标

iPad 服务器、公网 / 穿透、密码、HTTPS、DLNA / AirPlay、在应用内嵌浏览器当播放器。

## 验收

红米打开开关，电脑浏览器访问显示的地址：能播已有录像；插上采集卡后现场有画面和声音；可同时本地录像；关掉开关后地址失效。
