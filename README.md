# USB Studio

Android 应用：把 HDMI USB 采集卡的画面和声音接到手机、平板或电视上，可以预览、监听、截图、录成 MP4，也可以推 RTMP 或在同一 Wi-Fi 下用浏览器看。

应用名 **USB Studio**。仓库是 Flutter 应用 + 本地插件 `packages/usb_capture`。采集走 USB Host + UVC，不走系统内置摄像头。

## 能做什么

- **预览**：UVC 采集卡实时画面；无信号会提示，而不是一直黑屏。
- **监听**：采集卡音频；可静音、调音量、加 0–200ms 延迟。
- **截图**：保存当前采集画面（不是 App 界面截图）。
- **录制**：H.264 + AAC 的 MP4。默认定时分段，锁屏或切到后台可继续录。
- **片库**：列出本应用保存的片子；点标题用系统播放器打开；可分享、删除、重命名；同一场多分段可合并。
- **推流**：`rtmp://` / `rtmps://`，可与本地录像同时进行。
- **局域网播放**：本机起 HTTP 服务。不插卡也能看已录成片；插上卡后提供现场 HLS。

电视和手机共用同一个 APK：电视走 10 英尺遥控布局（Leanback），手机/平板走触控。

## 环境和硬件

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 7.0+（minSdk 24），ARM 32/64 |
| 电脑 | Flutter stable，Dart SDK `^3.13.3` |
| 采集卡 | UVC 视频，通常带 UAC 音频 |
| 连接 | 手机/平板用 USB OTG；电视/盒子用 USB Host |

模拟器验不了采集。真机注意：

- 供电不足时用带供电的 USB Hub。
- 不少电视 USB 口只认 U 盘；打不开会有明确错误。
- 部分机型（如 MIUI）可能拦截后台续录或分段合并，需要忽略电池优化。
- 不支持 iOS、桌面、内置摄像头、RTSP/SRT/WebRTC。

已在红米 Note 9 4G（M2010J19SC）上做过预览、监听、录制、片库和锁屏续录验收。

## 仓库结构

```
lib/                          # Flutter 界面：预览页、片库、偏好
packages/usb_capture/         # 采集插件（Dart 接口 + Android 原生）
  android/                    # UVC、录像、RTMP、局域网 HTTP
  lib/                        # 插件 API
openspec/                     # 规格与变更记录
test/                         # Widget / 逻辑测试
```

原生采集主要在 `packages/usb_capture/android`：UVCAndroid 开卡，MediaCodec 编码，Pedro RTMP 推流，NanoHTTPD + HLS 做局域网播放。

## 构建

```bash
flutter pub get
flutter test
flutter build apk --release
```

安装（把序列号换成你的设备）：

```bash
adb -s <serial> install -r build/app/outputs/flutter-apk/app-release.apk
```

应用 ID 是 `io.github.flyedmonkey.usbstudio`。以前装过「USB采集」的，请先卸载旧包，否则桌面上会同时出现两个图标。

调试：

```bash
flutter run
```

首次打开会申请相机、麦克风、USB 权限。录制和局域网播放会拉起前台服务通知。

## 怎么用

1. 插入采集卡，必要时授权 USB。
2. 只有一张卡时会自动连接；多张卡可在顶栏切换。
3. 底部：**推流**、**开始录制**、**预览静音**。
4. 右上角：**截图**、**片库**、**设置**。点预览可进出全屏；电视用「全屏」和返回键。

### 录制

默认每 10 分钟一段。文件名：

- 分段：`USB_YYYYMMDD_HHMMSS_01.mp4`
- 整场：`USB_YYYYMMDD_HHMMSS.mp4`

默认保存到相册 `DCIM/UsbCapture`，也可改成影片、下载或自定义目录。拔卡时若当前段有内容，会尽量收成可播文件。

画质（按 1080p 大约值，会随分辨率缩放）：

| 选项 | 约每分钟 |
| --- | --- |
| 更小 | 15 MB |
| 省空间 | 30 MB |
| 标准（默认） | 60 MB |
| 高码率 | 120 MB |

### 片库

点一行标题用系统播放器打开。分享、删除、重命名是各自的按钮，不会误触播放。同一场至少两段时显示「合并本场」：复制已有音视频轨，不重新编码；原分段保留。合并后的名字优先 `USB_<场次>.mp4`。改过名、不再符合分段命名规则的条目不再显示合并。

### 推流

在设置里填：

- **推流地址**，例如 `rtmp://live.example/live`
- **推流密钥（选填）**：也可以把带 key 的完整地址填在上面

`rtmp://主机` 这种只有主机、没有路径的地址会被拒绝。推流和本地录像可以同时开。平台 CDN（例如 B 站）本身可能再缓冲几秒，这部分压不掉。

### 局域网播放

设置里打开「局域网播放」（默认关）。界面会显示类似：

```
http://192.168.1.8:8080/
```

同一 Wi-Fi 下用浏览器打开即可。不设密码、不做 HTTPS、不穿透外网。现场画面要等采集卡连上；已录成片不插卡也能看。

## 设置

| 分组 | 内容 |
| --- | --- |
| 语言 | 跟随系统 / 简体中文 / 繁體中文 / 日本語 / 한국어 / English |
| 录制 | 分段时长（关闭 / 1 / 5 / 10 / 15 / 30 分钟）、画质、保存位置、连接后自动开录 |
| 预览 | 开关预览、预览声音、监听音量、监听延迟 |
| 画面 | 采集卡格式（常见默认 1080p30 MJPEG，电视可偏向 720p）、亮度/对比度/饱和度/色调 |
| 推流 | 地址、密钥 |
| 局域网播放 | 开关和本机 URL |

推流和局域网不常用，放在设置最下面。录像或推流进行中不能改画质和视频格式。

## 测试

不插采集卡也可以跑：

```bash
flutter test
cd android && ./gradlew :usb_capture:testDebugUnitTest
```

真机步骤记在 `test/hardware_acceptance_test.dart`（默认 skip）。换机或换卡时按里面的清单再验一遍：预览、监听、成片进所选位置、片库、锁屏续录、录制中拔线。
